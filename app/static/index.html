Portainer CE

Inspect Docker containers, images, storage volumes, logs and the Compose application running on the Ubuntu ECS.

Open Portainer HTTPS ↗

Important: Portainer manages the Docker host, not the nested Kubernetes cluster directly. Initial setup creates a separate Portainer administrator account.

A self-signed HTTPS certificate warning is expected on first local access; never expose Portainer over an untrusted network.

Suggested 90-Minute Class

0–10 min: Verify cluster / pods / services. 10–25: Blue–Green and rollback. 25–45: Canary at 10, 25 and 50%. 45–60: Rolling releases and ReplicaSets. 60–75: Scaling, HPA, events and logs. 75–90: Grafana panels and Portainer.

Capture a screenshot of the traffic split and new ReplicaSet before the end of the practical.

Technical Evidence for Assessment

Students should demonstrate (1) both versions have Ready Pods, (2) the live demo changes with the blue/green switch, (3) canary samples include both versions, (4) rolling update creates a new ReplicaSet, (5) scale changes desired and ready replicas, and (6) Grafana shows new requests.

It is not enough to open the dashboard. Verified Kubernetes changes count as progress.
